COACH: Fair enough — this is a small JavaScript convenience feature,
not something you'd necessarily encounter unless someone points it
out.

{ title, categories } is called object shorthand property syntax.
It's just a shortcut. When you write:

{ title, categories }

JavaScript looks at the variable names you already have (title and
categories) and automatically builds:

{ title: title, categories: categories }

So the two forms are functionally identical — same object, same
result. The shorthand only works because your variable names happen
to match exactly what you want the object's keys to be called. If you
had a variable called pageTitle but wanted the EJS template to see it
as title, you'd have to write it the long way: { title: pageTitle }.

That matters practically because it's why your EJS file can just
write <%= title %> — EJS receives an object with a key literally
named title, and whatever variable name you used to build that value
on the Node.js side doesn't matter to EJS at all; only the key name
does.
